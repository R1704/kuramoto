# Lessons

- 2026-05-12: The project/model name is Kuramoto. Do not infer or reuse "Coremoto" when discussing this repo or the Imaginarium notes.
- 2026-06-10: "Browser verification" that only checks console cleanliness + element presence is NOT verification of dynamics. Several Rule 7 phases passed such checks while the model produced grid-filling mush and a vacuous coherence gate. Rule: any change to simulation dynamics must be validated quantitatively via field readback (`window.__kuramotoDebug.sim.readMatterField()/readOrderField()`) against an expected regime (localization, contrast, equilibrium values), not by "it loads and runs".
- 2026-06-10: Before sweeping a parameter, check it can change the attractor. `ncaGrowthK` multiplies the entire da/dt bracket — it only rescales time, so sweeping/ranking it is meaningless. Equilibrium analysis first, sweeps second.
- 2026-06-10: When a controller sets state and pushes to the GPU, verify it uses the FULL sync path. The sweep controller called only `sim.updateFullParams(state)`, which writes the global uniform block — per-layer params (growth/NCA/kernel/gauge) live in a separate buffer written by `writeLayerParams` after `syncStateToLayerParams`. Every layer-param sweep silently swept nothing for weeks. Rule: after any "set param → measure" automation, assert the dynamics actually changed (e.g., two extreme values produce different fields).
- 2026-06-12: When telling the user where something lives in the UI, verify the exact tab and button label from index.html (which `data-tab-pane` the element falls inside, the literal button text) before answering. I claimed presets were in the Simulation tab and called the button "Mitosis"; they are in the **Dynamics** tab under "Lenia / Artificial Life", labeled "KuramotoNCA Mitosis". Grepping for an element is not the same as locating it in the user's view.
- 2026-06-12: ALL sim readbacks (`readTheta`, `readOrderField`, `readMatterField`, ...) share one `thetaReadPending` mutex and return null instead of waiting when it is held — `Promise.all` over two readbacks silently nulls the second. Read sequentially. Do NOT split the flag per-function: `resize.js` spin-waits on it before destroying buffers. Caught only because the new code path was exercised in the browser before being declared done — structural verifier checks alone (regexes) had already passed on the broken Promise.all version.
- 2026-06-12: "I see no effect from slider X" — before assuming a wiring bug, verify the param reaches the GPU (it did: onParamChange runs applyLayerStateToSimulation -> writeLayerParams) AND check whether the effect is physically conditional. ncaPhaseLag only produces motion given a persistent phase gradient + binding>0 + an unpinned organism; on normal presets it correctly does nothing. Confirmed live with a readback test: flipping chi 0.8->-0.8 reversed a ~90-cell drift. The real gap was discoverability/visibility (the demo blooms into a lattice whose sliding is hard to see), not correctness. Fix UX + guidance, don't "fix" a working feature.
